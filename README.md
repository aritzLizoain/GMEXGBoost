# GMEXGBoost: Generalized Mixed-Effects Xtreme Gradient Boost

This repository provides the R scripts accompanying the paper:
**"GMEXGBoost: A Hybrid Framework Integrating GLMM and XGBoost for Correlated and Hierarchical Data"**.

## 📘 Overview
The GMEXGBoost model integrates Generalized Linear Mixed Models (GLMM) with Extreme Gradient Boosting (XGBoost) to handle hierarchical and longitudinal data structures efficiently.
 

## ⚙️ Requirements
- R version ≥ 4.2  
- Packages: `xgboost`, `lme4`, `tibble`, `dplyr`, `ggplot2`, `stringr`,'glmertree','randomForest'
